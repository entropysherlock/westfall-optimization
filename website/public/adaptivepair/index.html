Research note: Waiting for the actual ATLAS-075 API.
Methodological limits: This workspace sends synthetic demo records to the API you configure. Respondent-cluster bootstrap intervals do not correct adaptive assignment, self-selection, fatigue, missingness or post-hoc contrasts. No customer data should be sent without appropriate authorization.

Built around practical decisions

Two engines. One clear workflow.

Designed to complement an existing survey product, not replace its respondent interface or its familiar reporting.

01 / SELECT

Choose the next pair

A balanced, coverage-aware selector proposes an eligible matchup. Experimental adaptive policies are available through the backend.

02 / MEASURE

Track the gaps

Retain familiar observed win rates while separately checking model-based comparisons and uncertainty.

03 / QUALIFY

Report what is supported

Use warnings and interval estimates to distinguish visible score differences from differences the available data can actually justify.

Research and integration

Built for evaluation, not hype.

The Python/FastAPI backend combines matchup selection and respondent-aware bootstrap diagnostics in one API. The workspace above calls the ATLAS-075 /v1/decision-support and /v1/confidence endpoints when connected. Adaptive-sampling calibration and customer-data validation remain open work.
