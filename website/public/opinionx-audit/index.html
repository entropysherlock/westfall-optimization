What this audit can—and cannot—tell you

Supported now

Exact observed scores, comparison counts, opponent-coverage patterns, and descriptive bootstrap uncertainty if respondent IDs are available.

Requires additional information

Unbiased uniform-opponent scores require design information or further assumptions; defensible early stopping requires a prospective, calibrated rule; observed ties are not proof of equivalence.

This tool never invents matchup-assignment probabilities. An unobserved pair cannot have its preference inferred without additional modeling assumptions. Confidence intervals here are exploratory and should not be used as guarantees for adaptive surveys.
Built for honest evaluation, not artificial certainty. Your CSV stays on your device; no API requests are made by this page.
Source and methodology

OpinionX documents Pair Rank as wins / appearances and Raw Data as individual vote exports. This tool accepts common column variants, or manual mapping. The bundled example is synthetic, not an OpinionX customer export. Bootstrap resamples full respondents rather than individual votes, conditional on the observed pair-assignment mechanism. It is not a valid design-based confidence interval for unknown adaptive assignment or informative nonresponse. If respondent IDs are absent, no interval is produced.
